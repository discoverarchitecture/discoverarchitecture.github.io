# Guide topics, in order (weekly guides; owner, 15 Nov 2026)

The weekly routine (`WEEKLY.md`) takes the top two topics that are not yet written, and moves them to "Done" with the
date. Every topic must pass the owner's test (10 Nov 2026, when free board grids were turned down): **would a student
working on a project be glad they found this page?** Search demand alone is not enough. Add new topics from Search
Console queries (`search_console/latest.json` on `analytics-data`), the site's found-nothing searches (`events.csv`,
`search/none/...`) and questions students ask; check each against the existing guides first (`CHECKLIST.md`: no
near-duplicates).

## Next

1. **How to write an architecture project statement** (search: architecture design statement, concept statement
   example). 100–200 words, what to say, before/after with made-up examples labelled as such.
2. **Architectural scales explained: 1:500 to 1:5, and 1/8" = 1'-0"** (search: architectural scale, 1:100 scale).
   What each scale shows, metric and imperial, scale bars, printing at the wrong size.
3. **How to make an architecture model: materials, scale and tools** (search: architecture model making, model
   materials). Massing vs detail models, card, foam, wood, cutting, glue, base, time plan.
4. **How to draw an exploded axonometric** (search: exploded axonometric architecture). Choosing layers, angle, gaps,
   line weight, labels; by hand and in Rhino/Revit/SketchUp.
5. **How to draw a section perspective** (search: section perspective architecture). Cut, vanishing point, people,
   light; when it beats a plain section.
6. **How to read and respond to a design brief** (search: architecture design brief). Programme, site, constraints,
   questions to ask the tutor, turning it into a checklist.
7. **How to choose an architecture thesis topic** (search: architecture thesis topics). A question, a site, a
   programme; testing a topic before committing.
8. **Hand sketching for architecture students: what to practise** (search: architectural sketching). Lines,
    perspective, people, quick site sketches, keeping a sketchbook.
