## 5. Reddit and Quora: answer, don't advertise

r/Architects removes self-promotion outright; r/architecture and r/archviz have their own rules: read each sidebar
first. The safe pattern everywhere: answer the question fully in the post itself; link a guide only when it adds
something (a picture, a table) and say it's yours. Never link `/studio/` directly in an answer unless someone asks for a
tool.

Questions worth answering (search them on Reddit and Quora): "how to lay out an A1 architecture board", "what size is
a 24×36 sheet in A1", "tips for my first architecture jury", "how to present site analysis", "concept diagram ideas".

**Draft answer: "How should I lay out my A1 board?"**

> Decide four things before placing any drawing: orientation (check the brief), a margin (20–25 mm all round is a good
> start), a column grid (four columns on portrait A1, six on landscape, 10 mm gutters) and a reading order (top left to
> bottom right: idea and hero image first, then site, plans, sections, details). Make your strongest drawing the
> biggest thing on the sheet, keep text blocks one or two columns wide, and print an A3 check: if it reads at A3, it
> reads at A1. I wrote this up with a sample board here [guide link], disclosure: it's my site.

**Draft answer: "Is 24×36 the same as A1?"**

> No. 24×36 in (ARCH D) is 610×914 mm; A1 is 594×841 mm. ARCH D is a 2:3 rectangle, A1 is 1:1.414, so an A1 layout
> scaled to fill the 24-inch width leaves about 50 mm of length empty. Either re-lay the grid or use the extra length
> for a title band. Use scale bars, not written scales, because they stay true when the board is printed smaller.
> Full table of sizes, in mm, inches and pixels: [guide link] (my site).
